# Website CMS guide

1. Sign in with an authorized admin/co-admin account.
2. Open Admin Dashboard → Content → Website CMS.
3. Select the content type (Pages, Services, Products, Portfolio, Industries, Blog/Insights, Careers, Testimonials or Site settings).
4. Create an entry with a title and URL slug. Add a short summary and body.
5. Keep the status as Draft while reviewing. Change to Published only after the content is approved.
6. Edit an existing record using Edit. Use Archive to hide it from public results while retaining the database record.
7. Published Services, Products, Portfolio, Industries and Insights are exposed through the public content API. Public templates display CMS records when present and otherwise show clearly generic placeholder content.
8. Use Admin Dashboard → Content → Media Library to upload approved image/PDF assets after Cloudinary has been configured.

Do not publish client names, logos, testimonials, statistics, certifications, addresses or project outcomes unless they have been verified and approved.
