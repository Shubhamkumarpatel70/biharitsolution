# Website CMS guide

1. Sign in with an authorized admin/co-admin account.
2. Open Admin Dashboard → Content → Website CMS.
3. Select the content type (Pages, Services, Products, Portfolio, Industries, Blog/Insights, Careers, Testimonials or Site settings).
4. Create an entry with a title and URL slug. Add a short summary and body.
5. Add an optional category and comma-separated tags. These can be used by public content filters.
6. To add a featured image, first upload an approved image in Admin Dashboard → Content → Media Library. Return to the CMS editor and select that image from the Featured image list. Add meaningful alt text for accessibility. Only secure Cloudinary image URLs are accepted by the CMS API.
7. Keep the status as Draft while reviewing. Change to Published only after the content is approved.
8. Edit an existing record using Edit. Use Archive to hide it from public results while retaining the database record.
9. Published content is exposed through the public content API. The API supports category, tag, text search and page/limit query parameters; only published records are returned.
10. Public templates show CMS images, summaries, body text, categories and tags when available. Generic placeholder content is used when no CMS content exists.

Do not publish client names, logos, testimonials, statistics, certifications, addresses or project outcomes unless they have been verified and approved.
